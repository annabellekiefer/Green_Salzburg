# Green Salzburg: Eco-Friendly Living & Eating

## Overview
**Green Salzburg: Eco-Friendly Living & Eating** is an interactive Leaflet map highlighting eco-friendly and sustainable places in Salzburg. The map provides an overview of green restaurants, sustainable shops, and recycling stations in the city. It is designed for both locals and tourists who are looking for environmentally friendly options and want to promote a sustainable lifestyle.

## Target Audience
- **Locals in Salzburg** who are seeking sustainable food, shopping, and activities.
- **Tourists** who want to discover eco-friendly options during their stay in Salzburg.
- **Environmentally conscious individuals** who want to find sustainable alternatives in an urban setting.

## Features
- **Interactive Map**: Displays the best green locations in Salzburg.
- **Filter Options**: Users can filter by categories such as "Sustainable Restaurants", "Eco-Friendly Shops", and "Recycling Stations".
- **Map Markers**: Each location is represented by a marker, providing additional information such as the name, address, and description.

## Folder Structure
The map is organized with three main files and a folder structure for the web application.

### 1. **index.html**
The HTML file forms the basic structure of the web application. It contains the layout of the page and loads all the necessary resources (CSS and JavaScript) to display the Leaflet map correctly.

### 2. **main.js**
The JavaScript file contains the logic for the Leaflet map. It loads the map data, places the markers, and enables the user to interact with the map. This is also where the popups for each location are created.

### 3. **style.css**
The CSS file handles the visual design of the map and the webpage. It ensures the map functions well on both desktop and mobile devices.

## Creation
This map was built using **Leaflet**, an open-source JavaScript library for interactive maps. The data for the map was sourced from **OpenStreetMap (OSM)** using **Overpass Turbo** to extract eco-friendly and sustainable locations in Salzburg. The markers and symbols were custom-designed to ensure a clear and effective visualization of these locations, making it easy for users to differentiate between various categories. The map was designed to work seamlessly on both desktop and mobile devices.
